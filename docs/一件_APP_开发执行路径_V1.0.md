# 「一件」APP 开发执行路径

> 版本：V1.0  
> 平台：Android  
> 目标：把已经封板的产品规则转化为可安装、可测试、可发布的本地优先 MVP  
> 推荐技术基线：Kotlin / Jetpack Compose / Navigation Compose / Room / DataStore
> 开发决策修订：2026-09-02 · 本地签名 APK 发布

---

## 1. 文档用途

本文用于回答三个问题：

1. 开发从哪里开始；
2. 每一阶段具体完成什么；
3. 达到什么条件才能进入下一阶段。

需求优先级按照以下文档执行：

1. 《一件_APP_V1_开发决策基线.md》：已确认的工程、产品、隐私和发布决策；
2. 《一件_APP_产品需求文档_PRD_V1.0.md》：产品逻辑与业务规则；
3. 《一件_APP_前端调整与交互实现清单_V1.0.md》：页面、视觉和交互；
4. 《一件_APP_开发任务拆解与验收用例_V1.0.md》：任务、数据和验收口径；
5. 《一件_APP_验收测试方案_V1.0.md》：测试步骤、测试记录和发布门禁；
6. `design/screens/` 与 Figma：页面结构与视觉参考。

发生冲突时，不允许开发自行扩展产品范围；先按以上优先级收口。

## 2. 最终交付目标

V1 必须完成以下闭环：

```text
欢迎
→ 创建一件事
→ 首页未完成
→ 完成今天
→ 首页已完成
→ 查看记录
→ 中断后继续
→ 设置与提醒
→ 结束当前目标
→ 查看历史
→ 开始下一件事
```

发布前必须满足：

- 同时最多一个 ACTIVE 目标；
- 同一目标同一自然日最多一条 Completion；
- 核心功能完全离线可用；
- 杀进程、重启和跨天不丢数据；
- 中断后 currentStreak 正确重启，totalCompleted 和 longestStreak 保留；
- 结束目标后历史保留，不能返回 ACTIVE 首页；
- Release 不包含文字记录、INTERNET 权限或第三方 Analytics/Crash/广告 SDK；
- 本地签名 APK 可安装，并记录 Git commit 与 SHA-256；
- 25 条 P0 验收用例全部通过。

---

## 3. V1 明确不进入开发的内容

- 多目标并行；
- 登录、注册和云同步；
- 补签、撤销历史完成记录；
- 任何文字记录、备注、日记、图片或附件；
- 社区、好友、排行；
- 积分、金币、商城和复杂徽章；
- AI 对话或建议；
- 数量型、计时型和“坚持不做”型目标；
- 复杂周报、月报和趋势图。

发现以上需求时，记录到后续版本列表，不进入当前迭代。

## 4. 推荐工程结构

```text
app/
├─ data/
│  ├─ local/
│  │  ├─ entity/
│  │  ├─ dao/
│  │  ├─ database/
│  │  └─ datastore/
│  ├─ repository/
│  └─ mapper/
├─ domain/
│  ├─ model/
│  ├─ usecase/
│  └─ calculator/
├─ notification/
│  ├─ scheduler/
│  ├─ receiver/
│  └─ worker/
├─ analytics/
│  └─ AnalyticsTracker
├─ ui/
│  ├─ navigation/
│  ├─ component/
│  ├─ welcome/
│  ├─ create/
│  ├─ home/
│  ├─ records/
│  ├─ settings/
│  ├─ endgoal/
│  └─ history/
└─ core/
   ├─ date/
   ├─ design/
   └─ util/
```

约束：

- 日期计算集中在一个可测试模块，不散落在 ViewModel 中；
- 页面只消费状态和发送事件，不直接访问数据库；
- 提醒通过统一 Scheduler 接口管理；
- AnalyticsTracker 保留接口，Release 使用 NoOp 实现；
- 业务数据不依赖网络。

> V1 执行原则：先完成一个真实可用的闭环，再逐步增加状态；状态正确性永远优先于视觉动效。
