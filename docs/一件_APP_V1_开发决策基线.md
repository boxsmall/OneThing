# 「一件」APP V1 开发决策基线

> 版本：V1.0 基线 + V1.1 修订
> 锁定日期：2026-09-02；V1.1 修订：2026-09-05
> 状态：V1.1 已确认，并完成双 API 模拟器、Xiaomi Android 14 实体机与正式覆盖升级验收
> 适用范围：V1/V1.1 Android 本地发布版

## 1. 文档地位

本文记录 V1 开发前已经确认的工程、产品、设计、数据、隐私和发布决策。其他文档存在旧描述或歧义时，以本文和已同步修订后的 PRD 为准；不得在开发过程中自行恢复已排除的功能。

## 3. V1 产品边界

- 同时最多一个 ACTIVE 目标。
- 每个目标每个本地自然日最多一条 Completion。
- V1 完全不支持文字记录、备注、日记、图片或附件。
- 不支持补签、撤销完成、编辑历史完成记录、恢复已结束目标或清空历史。
- 不支持账号、登录、云同步、多目标并行、社区、排行、积分、会员和 AI 功能。
- 允许同一天结束旧目标并创建、完成新目标；唯一约束作用于 `(goalId, date)`，不建立全局日期唯一约束。

## 4. 目标输入规则

- 目标名称为单行必填文本，最多 20 个用户可见字符。
- 提交前去除首尾空白；不允许空字符串、纯空白和换行。
- 允许中文、英文、数字、内部空格和 Emoji。
- “走路 20 分钟”仅作为 placeholder，不自动写入输入框。
- 输入非法或为空时，“开始坚持”不可提交。
- 设置中可以修改当前目标名称，但不得新建 Goal、变更 goalId、重置 startDate 或统计。

## 5. 日期、进度与统计

- 所有业务日期以设备当前时区的本地自然日为准。
- 7 日进度固定展示“过去 6 天 + 今天”，按从旧到新排列。
- 目标开始日前、目标结束日后和未来日期使用中性空状态，不计为未完成。
- 月历以周一为一周起始日，使用 7 列自适应网格。
- 今天未完成而昨天完成时，`currentStreak` 只计算到昨天；今天完成后才加 1。
- `totalCompleted`、`currentStreak`、`longestStreak` 从 Completion 真实记录计算，不保存可失真的派生缓存。
- 历史目标按 `endDate DESC` 排列；同日结束时按创建时间倒序。

## 6. 数据一致性

- Completion 建立唯一索引 `(goalId, date)`；UI 同时防抖，数据库结果是最终事实。
- Goal 增加可空唯一槽位 `activeSlot`：ACTIVE 时固定为 `1`，ENDED 时为 `null`，利用唯一索引从数据库层保证最多一个 ACTIVE Goal。
- 创建、完成、修改、结束和开始下一目标都通过 Repository 事务执行。
- Room 保存 Goal 与 Completion；DataStore 仅保存欢迎状态等轻量设置。
- 云备份关闭；允许设备到设备迁移 Goal、Completion 和非敏感设置。
- 提醒任务、通知权限结果和随机安装标识不迁移；恢复后按当前系统权限重新调度。

## 7. UI 实现口径

设计源为仓库 `design/screens/` 下 11 张 `360 × 800` PNG。Compose 实现以该尺寸为视觉基准，但必须响应式适配 320–600dp 宽度、大字体和系统安全区，不使用绝对坐标复刻。

### 7.1 主题 Token

| Token | 值 |
| --- | --- |
| 页面背景 | `#FDFBF7` |
| 未完成背景 | `#FCF9F4` |
| 完成绿 | `#59AD5E` |
| 待完成黄 | `#F5B838` |
| A1 品牌黄 | `#FABF45`（仅用于 Logo 圆点） |
| 危险红 | `#E05252` |
| 主文字 | `#141414` |

V1 仅提供浅色主题。系统处于深色模式时仍保持浅色页面，并正确设置系统状态栏和导航栏图标对比度。手机竖屏为主要设计目标；页面必须可滚动，避免横屏或大字体时裁切。所有可点击区域至少 `48dp × 48dp`。

### 7.2 已确认的设计修正

- 所有首页状态统一使用右上角齿轮设置入口。
- 目标图标使用固定的“一件”品牌 `1.` 图形，不提供用户选择图标；未完成使用黄色容器，已完成使用绿色对勾。
- A1 Launcher Icon 使用黑色数字、品牌黄 `#FABF45` 圆点和 `#FDFBF7` 背景；品牌黄与待完成状态黄 `#F5B838` 是不同 Token。
- `03 首页 未完成` 中今天尚未完成时不得提前把今天计入 currentStreak。
- `04 完成反馈` 是首页 Overlay，不是独立路由；数据库落库成功后显示，约 1.2 秒关闭，允许点击关闭。
- `06 坚持记录` 使用不会重叠的 7 列月历，统计卡片位于完整月历之后。
- `09 结束目标确认` 的“继续坚持”必须呈现为可点击的安全操作，不得使用类似禁用态的样式；“结束这件事”使用危险红。
- `11 我的历史` 卡片高度自适应，完整展示名称、日期和统计，不裁切第三行。
- 历史页使用标准返回导航；从设置进入返回设置，从结束结果进入返回结束结果。

## 8. 通知

- 创建目标时提醒默认开启，默认时间为 20:00；用户可以关闭。
- 仅在用户实际开启提醒时请求 `POST_NOTIFICATIONS`。
- 使用单次、非精确系统提醒；不申请精确闹钟特殊权限。
- 每次触发或系统时间、时区、重启、应用更新发生变化后，按下一次本地 reminderTime 重建计划，避免周期漂移和重复任务。
- 如果创建或修改提醒时当天时间已经过去，下一次安排在次日，不补发过期通知。
- 当天完成、关闭提醒或结束目标后取消当天剩余及未来提醒。
- 通知锁屏可见性使用 `VISIBILITY_PRIVATE`，隐藏目标名称等正文。
- 小米、Redmi、POCO 在提醒开启时显示“系统提醒保障”入口，指导开启自启动并把省电策略设为无限制；保持单次非精确 Alarm 和无精确闹钟特殊权限的既定口径。

## 9. Analytics 与网络

- V1 不接入任何第三方 Analytics、Crash SDK、广告 SDK 或账号服务。
- 保留 `AnalyticsTracker` 接口，Release 使用 `NoOpAnalyticsTracker`，Debug 可以输出仅本机可见的结构化日志。
- 不生成或上传随机安装标识，不上传任何目标、使用行为或设备信息。
- 核心应用不声明 `INTERNET` 权限；如构建工具或调试组件引入网络能力，不得进入 Release Manifest。
- PRD 中原候选事件表保留为未来方案，不属于 V1 发布验收。

## 10. 本地发布与授权

- V1 发布渠道为本地签名 APK，不接入 Google Play 或其他应用商店。
- Release 产物必须使用固定 upload/release keystore 签名，密钥不得提交 Git。
- 每个发布包记录版本号、Git commit、构建时间、APK SHA-256 和完整验收结果。
- 仓库采用 Apache License 2.0，完整条款见根目录 `LICENSE`。
- `design/Android Adaptive Icon/` 中的 A1 资源被确认为 Android 品牌源稿；工程使用修正至 `66×66dp` 安全区的 VectorDrawable foreground/background，并提供 Android 13+ monochrome。V1.1 已启用资源包内 8 类目标图标，用于创建时明确选择、设置修改以及首页、记录页和历史页展示；完成动画继续固定使用 A1 `1.` Logo。

## 11. 关于与隐私

本地发布版的“关于一件”至少展示：

- 应用名称与版本；
- “目标与完成记录保存在设备本地”的说明；
- 不收集、不上传用户数据的 V1 隐私说明；
- Apache-2.0 开源许可证入口；
- GitHub 项目地址。

隐私政策随应用离线内置，不依赖外部 URL。未来进入公开应用商店前，再补充开发者主体、联系邮箱、公开隐私政策 URL、目标国家或地区以及商店 Data Safety/隐私申报。

## 12. 优先级修正

- 完成反馈的状态与 Overlay 行为是 P0；动画、触觉和细节精修是 P1。
- 历史列表、来源返回和数据隔离是 P0；空状态、筛选和视觉精修是 P1。
- 状态正确性、数据一致性和恢复能力优先于像素级动画。

## 13. 本地发布门禁

- Debug 与 Release APK 均可构建、安装和启动。
- 25 条 P0 用例全部通过。
- Room 唯一约束、事务、迁移与设备到设备恢复测试通过。
- API 26、API 36 和至少一台真实设备完成核心回归。
- Release APK 不包含 `INTERNET`、精确闹钟或无关敏感权限。
- APK 使用固定密钥签名并产出 SHA-256 校验值。
- 仓库不包含 keystore、密码、私密配置或用户数据。

## 14. V1.1 品牌体验升级修订（2026-09-05）

本节只修订与 V1.1 直接相关的口径；单目标、一天一次、完全不支持文字记录、本地数据、无账号/云同步/广告/Analytics 和本地签名发布等 V1 边界继续有效。

- 目标图标从“固定品牌图形”修订为 8 个用户明确选择的分类图标；默认及未知值均为 `other`，不根据目标文字自动猜测。首页、记录、设置和历史使用持久化图标；完成动画仍固定使用 A1 `1.` Logo。
- Room schema 升为 v2，新增 `iconKey TEXT NOT NULL DEFAULT 'other'`，必须通过显式 1→2 非破坏迁移，禁止 destructive migration。
- 启动页统一使用 AndroidX SplashScreen、暖白背景和 A1 Logo；只给 `MainActivity` 配置 Starting Theme，不创建第二个 Activity，不人为延长冷启动。
- 完成反馈升级为 1.8 秒、不循环的 Logo 点亮动画；Lottie 只承载图形层，动态天数、提示、业务状态、导航和语义继续由 Compose 负责。基础与 3/7/30 天资源失败时必须降级，不得阻断已写入的 Completion。
- 数据保存并可读后才触发动效；动画返回、切后台或进程重建均以数据库完成态为准，不重复写入或补播。
- `core-splashscreen 1.2.0`、`lottie-compose 6.7.1` 为 V1.1 锁定版本；版本号为 `1.1.0 (2)`。
- 实体手机测试可以按发布轮次单独执行，但任何未执行的真机或正式覆盖安装必须明确标为暂缓，不能用模拟器结果代替。
