# 一件（OneThing）

「一件」是一款极简的单目标坚持工具：用户只设置一件每天要做的事，完成后轻点一次，产品负责记录、提醒，并展示坚持进度。

## V1 产品边界

- 同时只进行一个目标
- 每天完成一次，记录完成或未完成
- 每天最多一次提醒
- 文字记录可选
- 暂不包含图片记录、补签、登录注册、社区、排行榜、积分、会员和商城
